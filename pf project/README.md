 # Game & Social Hub

A C++ game made with SFML. It has a Hogwarts theme, with a magic wand as the mouse cursor.

## Features
- **Game Hub** with three games:
  - Guess the Word
  - Memory Number
  - Drawing Recreation
- **House Quiz**: a 10-question quiz that sorts you into a Hogwarts house
- **Secret Letters**: win all 3 games to write a secret letter with a 4-digit PIN. Anyone with the PIN can read it.

## How to play
- Use the mouse to click buttons.
- Guess the Word: type letters on the keyboard.
- Memory Number: remember the 8 digits, then type them.
- Drawing Recreation: click squares to copy the picture, then press Check.
- Secret Letters: write your letter, choose a 4-digit PIN, and tell the PIN to your friend.

## How to run
1. Install Visual Studio and SFML.
2. Open the project and press Ctrl+F5.
3. Keep all pictures, fonts and sounds in the same folder as the code.
